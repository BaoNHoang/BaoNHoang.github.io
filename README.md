# Bao Hoang Portfolio

A simple personal portfolio built with HTML, CSS, and JavaScript.

## Design

- Rotating full-screen video backgrounds
- Minimal navigation and content panels
- Separate pages for career, education, background, and hobbies
- Responsive layout for desktop and mobile
- No framework or build process

## Run locally

```bash
python -m http.server 8000
```

Open `http://localhost:8000` in a browser.
